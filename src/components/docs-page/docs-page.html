1 Getting Started

Boba is a zero-build framework leveraging browser standards (Web Components, Light DOM styling, ES Modules) and Node.js v25+ native type stripping for ultra-fast performance.

# Scaffold a new Boba application
npx github:sholtomaud/boba my-boba-app
# Navigate and install dependencies
cd my-boba-app && npm install
# Launch live dev server
npm start
Note: Running npm start starts Vite dev server for on-the-fly type stripping and instant browser updates.

2 Web Components

Components inherit from BaseComponent, providing scoped styles, Light DOM integration for global Tailwind utility compatibility, and lifecycle hooks. 

import { BaseComponent } from '../../core/base-component.ts';

const html = `<h1 class="text-2xl font-bold text-slate-900">Hello World</h1>`;
const css = `:host { display: block; }`;

export class HelloComponent extends BaseComponent {
  static tagName = 'hello-component';
  constructor() {
    super(html, css);
  }
}

customElements.define(HelloComponent.tagName, HelloComponent);

3 Smart Client Routing

The built-in Boba Router supports client-side SPA navigation, path parameter extraction (:param), and automatic subpath support for GitHub Pages deployments. 

import { Router } from './core/router/router.ts';

const router = Router.getInstance();
router.registerRoute({ path: '/', component: 'home-page' });
router.registerRoute({ path: '/user/:id', component: 'user-profile' });

4 Global State

Lightweight state management backed by standard browser EventTarget events.

Define Store

new Store({ count: 0 })

Emits native custom events whenever state properties are updated.

Subscribe

store.addEventListener('change', ...)

Components listen to state changes inside their init() lifecycle method.
