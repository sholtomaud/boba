1 Getting Started & Scaffolding

Boba provides a lightweight scaffolding CLI to generate clean, production-ready applications powered by browser standards, native Web Components, and Vite.

# Scaffold a new Boba project
npx github:sholtomaud/boba my-app
# Navigate and install dependencies
cd my-app && npm install
# Start Vite development server
npm start
Note: During development, Vite provides instant HMR and on-the-fly type stripping for seamless browser testing.

2 Project Architecture & Structure

Boba maintains a clean, flat architecture where components, routes, and core utilities are explicitly organized: 

my-app/
├── index.html              # Main entry HTML file
├── package.json            # Node.js dependencies & scripts
├── src/
│   ├── main.ts             # Application bootstrapper & route definitions
│   ├── core/               # Core framework abstractions
│   │   ├── base-component.ts  # Base web component class
│   │   ├── store.ts           # EventTarget-backed state store
│   │   └── router/            # Client-side router engine
│   ├── components/         # Modular Web Components
│   └── styles/
│       └── global.css      # Tailwind v4 & design tokens
└── e2e/                    # Playwright end-to-end tests

3 BaseComponent & Light DOM Styling

Components inherit from BaseComponent. To allow full integration with Tailwind CSS utility classes, Shadow DOM is disabled in favor of Light DOM rendering with simulated style scoping. 

import { BaseComponent } from '../../core/base-component.ts';

const html = `<div class="p-4 bg-slate-100 text-slate-900 rounded-lg">Hello Boba</div>`;
const css = `:host { display: block; }`;

export class DemoComponent extends BaseComponent {
  static tagName = 'demo-component';
  constructor() {
    super(html, css);
  }
}

customElements.define(DemoComponent.tagName, DemoComponent);

4 Smart Client-Side Routing

The built-in Router provides seamless SPA navigation, dynamic route parameters (:param), and automatic base path resolution for subpath deployments such as GitHub Pages. 

import { Router } from './core/router/router.ts';

const router = Router.getInstance();
router.registerRoute({ path: '/', component: 'home-page' });
router.registerRoute({ path: '/docs', component: 'docs-page' });
router.registerRoute({ path: '/user/:name', component: 'user-page' });

5 Reactive State Management

State management uses native browser EventTarget events without standard heavy external state libraries.

Create Store

export const appStore = new Store({ count: 0 });

Updates state using setState() and emits native change events.

Listen in Components

appStore.addEventListener('change', ...)

Components subscribe inside init() to automatically update UI on changes.

6 Production Build & Deployment

To generate static production assets suitable for GitHub Pages, Netlify, or Vercel, run the production build script:

# Build static dist bundle
npm run build
# Preview static build locally
npx serve dist
